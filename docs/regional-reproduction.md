# 地域人口再生産率・合計特殊出生率

地域人口再生産率（RRR）は2020〜2024年度別に計算する。年度Yに、Y−4年1月1日からY＋1年1月1日までの日本人女性の5年コーホート比を対応させる。2020年度は2016→2021年、2024年度は2020→2025年。

年齢別出生率は、厚労省「平成30年〜令和4年人口動態保健所・市区町村別統計」の2018〜2022年ベイズ推定値を固定して使用する。年度差は人口の残存・移動の違いであり、その年の出生水準の変化を含む単年RRRではない。女児割合は100/205とする。年齢別の累積残存率は0〜4歳を1として、各5歳階級の同一コーホート人口比を累積する。分母が0、人口や出生率が欠測の団体には値を付けない。市町村合併や境界変更のコードを推測して接続しない。

合計特殊出生率は同じ公表表の合計特殊出生率列を使用する（丸められた年齢別率からの再集計ではない）。2018〜2022年の期間指標であり、年度間で固定。画面にもこの期間を表示する。2桁の都道府県・5桁の市区町村コードだけを読み、4桁の保健所コードは対象外。

## 再生成と検証

```powershell
npm run -w @local-gov/crawler update:reproduction
node --import tsx --test apps/crawler/tests/reproduction.test.ts
npm run -w @local-gov/crawler verify:data
```

通常の `import:demographics` も同じ計算を利用する。`update:reproduction` は既存JSONの該当2指標だけを更新し、全国結合データを再生成する。取得Excelは `apps/crawler/output/demographics/` にキャッシュする。

`data/demographics/reproduction.json` に公式表ID、URL、原本SHA-256、各年の女性年齢別人口、年齢別出生率、計算結果を保存。テストでは保存された入力から全年度の再計算一致を確認する。

出典：総務省「住民基本台帳に基づく人口、人口動態及び世帯数調査」各年のNN-08表。厚労省「人口動態保健所・市区町村別統計」[第2表](https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040174881&fileKind=0)。定義の参考：丸山洋平（2023）[マクロ統計データの組み合わせによる新たな地域人口分析指標](https://doi.org/10.24454/jps.2301005)。
