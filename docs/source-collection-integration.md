# 全国閲覧版への接続準備

この準備は既存画面や評価データを上書きしません。全国閲覧v5の正確な公開branch/commitを受け取ってから統合します。PR #1 (`97906005a4ca1b6b3cc0b8170d232d33320bda66`) は古いmasterを基にしているため、ブランチ全体を現行masterに置き換える方法は使用しません。道路・選挙コードと画面を保持します。

`buildCoverage` は既存 `apps/web/public/search-index.json` の5桁自治体コードを基準に、全1,741自治体の行を作ります。本文や抽出レコードの有無で自治体を除外しません。取得履歴は別の追加データとして自治体コードと原典URLで結びます。

## 表示の区別

- 公式原典リンクが確認された自治体・資料数。
- 実バイトを保存した自治体・資料数。
- PDF本文を読めるかの検証状態（取得だけで読取済みにしない）。
- 構造化レコードの状態（この処理は常に未実施）。
- 原典HTTP状態とプロキシHTTP状態。未特定通信失敗は拒否と表示しない。

集計の `scope` は `this_collection_batch_only` です。既存全国版の1,509自治体の関連資料案内、677自治体の本文、53自治体の構造化をこの小さな取得バッチの件数で置換しません。数値抽出の既存成果も変更しません。新規取得失敗は新たな試行状態として重ね、以前取得できた本文や抽出値を消さないようにします。重複原典は自動上書きせず、同一URLの既存ハッシュと日時を確認して統合します。

## 既存コードとの接続箇所

PR #1 の `EvaluationBrowser` にある原典カードは資料一覧を抽出事業カードから独立して表示しています。全国版ではこの区別を維持し、自治体選択肢は `projects` ではなく全国台帳から作ります。`evaluationYear` と `evaluatedFiscalYear` は原文確認が必要で、ファイル名・資料タイトル・一般的な `fiscalYear` メタデータからは転記しません。

静的JSONの取得先は既存 `apps/web/src/lib/paths.ts` の `dataUrl()` を使用し、`/local_gov_vis` のサブパスで検証します。新しい公開JSONの書き出しやHome/道路/選挙の画面変更は、この準備では行いません。

統合時には既存94テスト、全自治体検索、原典リンクのみの自治体、本文あり未構造化の自治体、プロキシ停止表示、道路・選挙の画面、型検査・lint・サブパス付き静的ビルドを確認します。
