# 事務事業評価の取得と原典付き閲覧

地方財政状況調査の `LocalGovBudget` と、自治体独自の `ProjectEvaluation` は別データです。
事務事業評価には国の統一CSVがないため、自治体ごとの公式索引をたどり、最新版としてリンクされている評価年度の資料を抽出します。
過去年度のURLを生成したり、現在年から評価対象年度を推測したりしません。

## 実行

```bash
npm ci
npm run -w @local-gov/crawler import:evaluations
# 初回の動作確認を文書数で制限（Excel一冊に複数事業が入る場合あり）
npm run -w @local-gov/crawler import:evaluations -- --limit 3
# 一つの自治体だけ更新。指定しなかった自治体のデータは保持
npm run -w @local-gov/crawler import:evaluations -- --source odawara
# 取得済みの原典から再現。ネットワーク接続なし
npm run -w @local-gov/crawler import:evaluations -- --offline
# 保存済み抽出結果を無視して再解析（原典キャッシュは利用）
npm run -w @local-gov/crawler import:evaluations -- --offline --force
# 不完全・未対応・失敗を終了コード1にする
npm run -w @local-gov/crawler import:evaluations -- --strict
npm run -w @local-gov/crawler test
```

`--limit` は自治体あたりの文書取得上限です（1〜500、カタログの上限以下）。
標準の上限を超える文書は取得しません。発見数と取得数を必ず表示し、全件取得したように見せません。
索引の探索にも上限があり、探索しきれない場合は不完全状態になります。
上限を引き上げる際は、各自治体の資料サイズ・アクセス条件を確認してからカタログを変更してください。

既存の財政データ再生成とは独立したコマンドです。`update:all` に含めず、既存の予算・決算JSONや集計を変更しません。
APIキー、LLM、外部OCR、ブラウザログインは不要です。定期実行は登録しません。

## データの意味

- `evaluationYear`: 自治体が明示する評価年度。公開日・ファイル名・当年から推測しない
- `evaluatedFiscalYear`: 実際に評価対象とされた年度。評価年度とは独立し、不明は `null`
- 金額: 予算、決算・実績、人件費、フルコストを別区分とし、年度と原表の単位・値を保存。明示された単位だけ円換算
- 人員の「人工」「人」は人件費金額ではない。未記載・抽出不可は `null` または空配列で保持し、0円と混同しない
- 指標: 目標・実績・単位を原文として保持。異なる指標・年度を足し合わせない
- 評価: 自己評価と外部評価を区分し、原文の評価ラベル・尺度を保持。自治体間のA/B/C等を同じ点数に換算・ランキングしない
- 予算マップとの接続: 自治体コードだけで閲覧画面へ接続。款・項と個別事業の同一性は自動推測しない

抽出は正確性100%を保証しません。未知の書式や画像だけのPDFは未対応、部分的な解析は不完全として公開します。
画面には取得状況と原典を表示し、原典の確認を優先できるようにします。

## 原典と再現性

全事業に元資料URL、発見元の公式ページURL、形式、SHA-256、初回取得時刻、抽出に用いた原文を保存します。
PDFはページ番号、Excelはシート・セル、HTMLは該当ページで位置を追跡します。
フィールド単位の金額・指標・評価にも根拠を保存します。

公開JSON:

- `data/evaluations/evaluations.json`
- `apps/web/public/evaluations.json`（同じ内容、静的配信）

ローカル保存（Git対象外）:

- `apps/crawler/output/evaluations/cache/`: URL別HTTP検証情報とSHA-256別原典バイト列
- `apps/crawler/output/evaluations/checkpoint.json`: 文書ごとの抽出結果とパーサーバージョン

原典が変わらなければ取得時刻・ハッシュは保持し、再解析を省略します。
HTTPのETag/Last-Modifiedがあれば条件付き取得します。オフライン再実行では取得時刻を更新しません。
文書ごとにチェックポイントと公開JSONを原子的に保存するため、中断後も同じコマンドで完了済みの解析を再利用できます。
パーサー変更時は `PARSER_VERSION` を更新します。
原典キャッシュはサイズ制限つきですが、過去の変更版も残るため、長期間の利用ではディスク容量を管理してください。

## 失敗と安全な取得

- HTTPSかつカタログにある公式ホストだけを許可。リダイレクト先も毎回検査
- 1秒以上のアクセス間隔、リクエスト数・探索数・本文サイズ・タイムアウト・再試行回数の上限
- 429と一時的な5xxは最大3回まで。長いRetry-Afterは無視して連続アクセスせず、その実行を失敗扱い
- 403を回避する別ドメイン・認証・プロキシ切替なし
- 前回取得済み資料を更新できなかった場合、そのデータを残し、今回の取得失敗と「前回取得分」を表示
- 公式索引の取得失敗時は、最新年度の確認に失敗したことを表示
- 文書状態は `ok / partial / failed / unsupported / pending`。原典がなくなっても成功と報告しない

PR検証は固定の原典抜粋とモックHTTPで実施し、自治体へのライブアクセスに依存しません。
最新版取得は上記の明示コマンドで実行します。取得そのものと、抽出できた項目の範囲は別々に確認してください。

## 全国版の固定検証済みデータと遅延読み込み

2026-10-12検証の全国コホートは、50自治体・12,259件の原典付き評価記録です。元のPR1の札幌3件・小田原582件・三郷3件はそのまま保持し、自治体コードと事業IDが重ならないことを確認して、画面の索引には計53自治体・12,847件を載せます。先行する別の未公開拡張版は、この集計には取り込んでいません。

件数は原典の評価記録単位です。同じ活動が複数の施策に再掲される場合があり、全自治体で重複排除された事業数ではありません。全国1,741自治体の最初の探索を終えたことは、全公開資料の発見や全事業の取得を終えたこととは異なります。

配信は次のファイルに分けます。

- `apps/web/public/evaluations-index.json`: 全国自治体の状況、表示対象件数、自治体別ファイルのSHA-256とバイト数
- `apps/web/public/evaluations-municipal/{自治体コード}.json`: 選択した自治体だけのPR1互換データ
- `data/evaluations/`: 入力版・元データ・自治体別ファイルの照合根拠

整理済み事業票を選んだときにこの索引を読み込みます。通常の初期画面は、後述の全国資料案内を使用します。自治体名の検索と、読み込んだ自治体の事業名・原文の検索は別です。全国の全事業本文を一括ダウンロードする検索ではありません。自治体の切替、戻る・進む、読取失敗後の再試行に対応し、古い要求の結果が新しい選択を上書きしないようにします。ロード済みデータの保持にも上限を設けます。

### 範囲と数値の注意

- 「探索では未発見」は、非公開という判定ではありません。取得済みで構造化未了、過年度のみ、取得停止も区別します。
- 全自治体の収集範囲は部分的です。掲載年度・評価対象年度・各金額や指標の測定年度は別で、不明な年度を補完しません。
- 検証済み全国コホートには、数値実績がある5,704記録が含まれます。同じ既知年度の直接費用と原典で成果と分類された指標が揃う記録は1,849件です。後者も因果効果の証明ではありません。元588件を加えてこの指標を再計算したものではありません。
- `recordsWithSourceLabelledOutcomeIndicators` は原典の成果分類の存在を表します。実績・目標の役割が不明な参照値を含むことがあるため、成果達成件数ではありません。
- 費用・成果の役割、年度、単位が確定しない観測、推計・見込み・計画、財源や人件費等の別成分は、完全な正規化データに保持します。旧PR1形式で安全に表せない値は画面用の金額・指標から除外し、原典と警告を残します。
- 低減目標、累計、時点値、定義変更等の注記がある指標は、原値を保持し、自動達成率の計算に使いません。自治体間の評価尺度の共通化・順位付け・費用の単純合算はしません。
- 過年度3,074記録と将来計画だけの64記録は、今回の現行表示件数から除外しています。

全国の取得・抽出と、この固定版の画面への取込みは分離しています。元の `import:evaluations` は元の3自治体の単一JSONを更新する取得コマンドです。これを実行しても、全国版の固定シャードを自動で書き換えません。全国の更新には、改めて原典と範囲を検証した入力版から索引・シャードを生成し、すべての照合とテストを通す必要があります。未検証のデータを上限だけ外して混ぜないでください。

```bash
# 明示した、原典・範囲検証済みのエクスポートだけを取込む（通信なし）
npm run -w @local-gov/crawler import:national-evaluations -- --source-dir /path/to/validated-export
```

この統合では、現在のmasterにある道路・選挙データや集計には変更を加えません。PDFライブラリもmasterの固定依存関係を維持し、元PR1の大きなバージョン変更は持ち込んでいません。


## 全国1,741自治体の資料・テキスト案内

`/evaluations/` の標準表示は全1,741自治体です。整理済み事業票のある自治体に限定しません。自治体名・都道府県・5桁コードを組み合わせて検索でき、府中市（東京都／広島県）、伊達市（北海道／福島県）などを区別します。全自治体の一覧を提供することと、全自治体の評価資料を取得済みであることは異なります。

新しい資料案内は既存の数値パーサー・型・整理済みシャードを変更せずに追加しています。自治体内の「資料・取得テキスト」を標準とし、「整理済み事業票」は独立した副表示です。予算・道路・選挙データや財政マップの集計には混ぜません。未公開の追加リリースは使用していません。

### 配信ファイルと収録範囲

- `apps/web/public/evaluation-evidence/index.json`: 全自治体の識別情報、探索状態、公式サイト案内、読める資料の件数、自治体シャードのバイト数・SHA-256
- `apps/web/public/evaluation-evidence/municipalities/{code}.json`: 自治体の資料一覧、原典URL、資料の役割・評価区分、確認根拠、取得状態、年度表記の根拠、テキスト資産のバイト数・SHA-256
- `apps/web/public/evaluation-evidence/documents/{sourceId}.json`: 一資料の未構造化テキストと自治体・出典・原資料ハッシュ・抽出テキストハッシュ
- `apps/web/public/evaluation-evidence/definitions.json`: 集計・分類・収録上限の定義

現在の件数は同梱索引から算出します。次は重複する集合なので合計しません。

1. 選択できる自治体：1,741
2. 確認済みの評価案内・索引ページがある自治体
3. 評価資料本文の取得テキストがある自治体
4. 案内・関連資料等も含めた公式資料のテキストがある自治体
5. 既存の整理済み事業票がある自治体

読める公式テキストには、事務事業以外の施策・施設・教育委員会の点検評価や、関連資料・案内ページも含まれます。資料の役割と評価区分を分けて表示し、案内ページを評価報告書の本文や構造化済み事業として扱いません。旧台帳の `unsupported` は形式未対応だけでなく内容・関連性の確認保留も含むため、アクセス制約とは別の「取得・内容確認で保留」と表示します。

小海町・宝達志水町などで他自治体の候補を除外した場合、除外件数と旧台帳の記録であることを表示します。過去の `fetched` から、その自治体の評価資料が取得できたとは推定しません。公式ホームページや公式自治体案内への代替リンクは、実際に確認したリンクだけを使います。

### テキストと原典の読み方

- 「取得テキスト（未構造化）」は抽出できた文字だけです。画像内の文字・図表・列の対応等が欠落する場合があります。
- テキストは一資料120,000 Unicodeコードポイントまで。省略時は全抽出文字数と配信文字数を表示し、検索も配信範囲に限定します。
- 索引ページのテキストは、リンク先の報告書を取得したことを意味しません。
- 年度は資料タイトル・公式リンク表記・本文の明示表記と引用を表示します。記載年度と評価対象年度を同一視せず、URL・更新日・取得日から補完しません。根拠がない年度は不明です。
- ZIP内部の資料は、格納元URL・格納元SHA-256・内部パス・内部資料SHA-256を分けて保持します。原資料リンクはZIPを開くことを表示します。
- テキストをReactの文字列として表示し、HTMLを実行・埋め込みしません。原典は安全なhttp(s)リンクで新しいタブに開きます。

### 読み込み・URL・再試行

最初は資料案内索引だけを読み込み、自治体を選ぶとそのシャード、資料を選ぶとそのテキストだけを取得します。すべて `dataUrl()` を通り、GitHub PagesのbasePathに対応します。自治体・資料・表示種別はURLの `municipality` / `source` / `view` に保持します。戻る・進むに対応し、自治体変更時には資料選択を解除します。

ストリームでサイズを制限し、索引8 MiB・自治体4 MiB・テキスト1 MiBを超える応答は拒否します。自治体・テキストそれぞれ最大3件／4 MiBのLRUキャッシュです。期待する正規のローカルパス、自治体コード・名称・都道府県、資料ID、URL、バイト数、SHA-256、文字数、集計件数を照合します。Web Cryptoを使えない環境は未検証であることを明示し、それ以外の照合を続けます。

要求を中断・タイムアウトさせ、旧要求が遅れて成功しても新しい選択を上書きしません。エラー・再読み込みはローカル配信資産に対するものです。画面を開いたり再試行したりしても自治体への自動取得は行いません。

### 追加の出典確認リンク

`data/evaluations/navigation-reviewed-sources.json` は、保存原本の取得とは別に行った出典確認を記録する。公式ページの本文・リンクで確認できた出典だけを確認済みにし、検索結果のみ・委任先ホストの公式な参照関係が不明なものは候補に残す。交付金、教育、施策、施設、行政改革、個別分野の資料は事務事業評価と区別する。

追加リンクは `navigationReview` を持ち、原本 SHA-256 は null、取得状態は未取得またはアクセス制約、本文は未取得のまま。確認メモ・年度メモは、保存原本の逐語的な証拠や数値抽出の代用にしない。先に保存した 2,389 本のテキスト資産・53自治体の構造化データは変更しない。
